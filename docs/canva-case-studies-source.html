ENGINEERING METHOD01 / EVIDENCE
Truth in technical storytelling

What does “verified” mean?

Keep illustrative geometry, working software simulations and physical measurements separate.

Concept / Pending

Architecture or illustrative CAD

A model or integration plan that has not yet been run or measured under real conditions.

Simulation-tested

Repeatable software behavior

A runnable test or browser model with known inputs, logic, outcomes and limitations.

Hardware-tested

Physical measurement

Requires a documented real setup, measured values, trial logs and failure context.

None of the PickBot V6, P6 Navigation or P2 Control Center portfolio demos is presented as hardware-tested.
